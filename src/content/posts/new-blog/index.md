# 前言

Hello and I'm Block_Fish。

最近事情比较多，学校方面的的事儿和在机房的硬件条件让我很难保证稳定产出、更新博客。

但是昨天参加某活动，专家大力表扬了这个博客项目——我是在“写”、是在“表达”、是在把我的知识努力告诉别人，这是和软件的自由化、开源化运动有点像的一样，是值得鼓励和支持的。

而且我也已经坚持了很久——如今已经是第 $4$ 个年头了，时光很快啊，我当然也不会就这么把它抛弃掉。

省流：不用担心断更，不保证长期稳定按什么频率更新，但一定会常来看看。

那么为了 ~~应付~~ 这个展会，我花费一定时间和精力（比较）彻底的翻修了网站，这里列一下版本目录（~~其实就是回忆录~~）。

# -1 梦开始的地方

其实最早开始有博客的想法是在 TX 云 Lighthouse 的「第三方教程」中的一个 [《搭建 Wordpress 博客》](https://cloud.tencent.com/developer/article/1692366)。

当然，穷（~~求打赏 Qwq~~），没钱搞域名、服务器，也没有资质做各种实名认证。

# 0.0 洛谷

洛谷应该是几乎所有 OIer 共同的回忆了。我作为少数的 $6$ 位数 UID 拥有者，最开始就是使用的洛谷博客。

后来事情也大家知道了，现在变成文章区了。我当时在洛谷上的一些篇目：

- 不少极早期的 ABC 的 C 题题解（~~审核一篇没过的那种~~）
- Python 安装指南
- Python GUI 界面入门
- 「你需要知道的一切」系列

当然，这些文章现在看来相当老旧了，这次顺带做了一点翻修，不过我并没有修改他们的主题，只改了一些明显的错误和格式，具体准确性、实用性之类的，呃呃……

# 1.0 开整！Hexo + Next

那有没有免费的方案呢？[洛谷日报](https://shwstone.cn/2022/07/26/hexo-next%E6%90%AD%E5%BB%BA%E5%8D%9A%E5%AE%A2/)。

从此 Hexo + Next 成为了我一段时间的 Blog 方案。部署平台上，GitHub Pages 和 Cloudflare Pages 成为了我的主力。至于 CMS，呃，配置了，但当时没弄懂怎么用。

另外似乎现在的 .eu.org 域名也是当时注册的，可惜现在似乎停止继续注册了。

后来因为太弱了，还要平衡文化课的原因，暂时抛弃了博客，有些文章也因此丢失（例如显存的「你需要知道的一切」系列其实是这一时期的光速重写版本，其质量可见一斑）。本 Blog 建立日期，$2023$ 年 $11$ 月 $25$ 日，也就从此算起。

这里，ABC 串讲系列就是我当时为了测试网站、丰富内容所作的。

# 1.1 Hexo + Next（重制）

后来呢，我又回归了 Hexo + Next。不过 Next 虽然提供了 4 款主题，但我个人都觉得不过好看（我虽然美术不好，但还是比较颜控的，比较喜欢绚丽的色彩、动画，当然，要以不影响阅读为前提，就像如果你认为目前的樱花动效太烦的话可以设置关掉）。

# 2.0 Hexo + Redefine

当时正是 xxs 的我（带不带引申义都对）比较迷恋「虚拟备案」这种东西（~~因为搞不了真的~~），加入了一大堆类似的网站，不过如您所见，他们运营的大部分没我的网站久。至于活下来的，多是像 [开往 Travellings](https://travellings.cn/)、[萌国 ICP 备案](https://icp.gov.moe/) 这样经营了多年的高质量、高口碑老牌项目了。

主力文章多产自这一时期，它几乎涵盖了我初中 $3$ 年的所有文章。谁能想到，我当初只是在一个这种备案、虫洞类的项目看见了一个用这个主题的人，就马上想要迁移了呢？

当然，这个主题 Bug 略多，包括但不限于：

- Hexo-sliding-spoiler 插件的兼容性
- Twikoo 评论的支持
- 直接使用 HTML 和 JS 的支持

这些普遍是刷新一下才能正常的，不过显然这当然算问题。不过这个主题配置很简单，_config.yml 只有 $400$ 多行。所以，近一年甚至更久的时间内我一直都在物色新的主题。

另外这一时期也发生了许多事情，例如我想改用户名啦、利用 CloudFlare 构建自定义域名邮箱啦之类的。

# 3.0 Hexo + Anzhiyu（腰斩）

但是配置过于复杂了，有很多需要跨文件联动的功能。我做不到。

所以最后写了很长时间配置文件，但根本写不完 /kel。
